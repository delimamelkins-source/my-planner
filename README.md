# My Planner - Supabase Setup

1. Create a free project at supabase.com, run `supabase.sql` in the SQL editor.
2. Copy Project URL and anon public key (Project Settings > API) into `script.js` (replace `PASTE_PROJECT_URL` and `PASTE_ANON_KEY`).
3. Optional: Authentication > Providers > Email > turn off "Confirm email" while testing.
4. After deploying to Netlify, add the Netlify site URL under Authentication > URL Configuration > Site URL.
